# ByteChat Emoji Shortcodes

You can use emoji shortcodes in your messages! Just type the code and it will automatically convert to emoji.

## Common Emoji Codes

### Smileys & Emotions
- `:smile:` → 😄
- `:grin:` → 😁
- `:joy:` → 😂 (laughing with tears)
- `:heart_eyes:` → 😍
- `:kissing_heart:` → 😘
- `:wink:` → 😉
- `:sunglasses:` → 😎
- `:sob:` → 😭
- `:cry:` → 😢
- `:angry:` → 😠
- `:scared:` → 😨
- `:thinking:` → 🤔
- `:face_palm:` → 🤦

### Hand Gestures
- `:+1:` or `:thumbsup:` → 👍
- `:-1:` or `:thumbsdown:` → 👎
- `:ok_hand:` → 👌
- `:wave:` → 👋
- `:pray:` → 🙏
- `:muscle:` → 💪
- `:v:` → ✌️
- `:point_right:` → 👉

### Hearts & Love
- `:heart:` → ❤️
- `:yellow_heart:` → 💛
- `:blue_heart:` → 💙
- `:purple_heart:` → 💜
- `:green_heart:` → 💚
- `:broken_heart:` → 💔
- `:sparkling_heart:` → 💖

### Objects & Symbols
- `:fire:` → 🔥
- `:sparkles:` → ✨
- `:star:` → ⭐
- `:tada:` → 🎉
- `:gift:` → 🎁
- `:bomb:` → 💣
- `:100:` → 💯
- `:boom:` → 💥
- `:poop:` → 💩
- `:beer:` → 🍺
- `:pizza:` → 🍕
- `:sun:` → ☀️
- `:moon:` → 🌙
- `:umbrella:` → ☔

### Status & Symbols
- `:ok:` → 🆗
- `:cool:` → 🆒
- `:new:` → 🆕
- `:free:` → 🆓
- `:x:` → ❌
- `:heavy_check_mark:` → ✔️
- `:question:` → ❓
- `:exclamation:` → ❗

## Example Messages

Try sending these:
- "I love this! :heart: :fire:"
- "You're awesome! :thumbsup: :sunglasses:"
- "This is sad :sob:"
- "Great idea! :lightbulb: :tada:"

All emoji codes are case-sensitive and must be surrounded by colons!
